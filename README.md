# Sudoku-Solver

Program that solves 9x9 sudoku boards.

Implemented techniques:
Pointing Pairs
Hidden Pairs
Naked Pairs
Sudoku/Last Digit
Naked Single
Hidden Single

Missing techniques:
Naked Triples
Hidden Triples
Naked Quads
Hidden Quads
X Wing
Y Wing
XYZ Wing
Swordfish
Probably some more super fancy ones
